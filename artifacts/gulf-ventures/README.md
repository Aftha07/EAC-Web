# Gulf Ventures Trading and Contracting LTD.

Premium corporate website for Gulf Ventures, a leading industrial contracting company operating in Saudi Arabia.

## Overview

Single-page React application showcasing Gulf Ventures' industrial solutions and services for major clients including Saudi Aramco, SABIC, Halliburton, and Baker Hughes.

## Design System

### Color Palette
- **Primary/Text**: `#111111` (near-black)
- **Accent**: `#C8102E` (deep red)
- **Background**: `#FFFFFF` (white)
- **Surface/Card**: `#F5F5F5` (light grey)

### Typography
- **Headings**: Barlow Condensed (bold, condensed, industrial)
- **Body**: Inter (clean, professional)

### Aesthetic
Industrial Authority — hard edges, precise alignment, dramatic photography, cinematic scale, confident whitespace.

## Sections

1. **Sticky Header** - Logo, navigation, Get a Quote CTA
2. **Hero** - Full-viewport with dramatic industrial imagery
3. **About** - Mission, Vision, Core Values
4. **Services** - 6 premium service cards with imagery
5. **Industrial Gas Supply** - Dedicated dark section with comprehensive gas listings
6. **Equipment Fleet** - 9 equipment categories
7. **Why Choose Us** - 9 feature highlights
8. **Clients** - Infinite scrolling carousel of 32+ major clients
9. **Contact** - Professional inquiry form + contact details + map
10. **Footer** - Company info, quick links, contact summary

## Features

- Smooth scroll navigation with scroll-spy
- Framer Motion animations (staggered reveals, parallax)
- Infinite CSS carousel for client logos
- Glassmorphism header on scroll
- Fully responsive (mobile-first)
- SEO optimized

## Technical Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- shadcn/ui components
- Lucide React icons
- React Icons (for WhatsApp logo)

## Running Locally

```bash
npm run dev
```

## Build

```bash
npm run build
```
